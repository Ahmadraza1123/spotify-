I have created an AHK (AutoHotkey) app related to Spotify.
In my app I’ve given new users the choice between Singer and Normal User.
Whenever a user is created and their email is added to the system, they will receive a welcome message.
If a user wants to change their password, a token will be sent to their email, and after that, the user can choose a new passwor.
Every user can edit their profile.
If the user’s role is Singer, they can only post songs.
Full CRUD operations (Create, Read, Update, Delete) are available for songs, albums, artists, playlists, and user profiles.
Like/Unlike songs and albums:Only Normal Users can like/unlike songs and albums.Every user can like or dislike content at any time.
Follow/Unfollow Artists:Only Normal Users can follow or unfollow artists.
Save songs/albums to the user’s library.
Search functionality for songs, albums, and artists.
